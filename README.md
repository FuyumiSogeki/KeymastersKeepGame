# KeymastersKeepGame
Keymaster's Keep games maintained by FuyumiSogeki

## Objectives
### Forza Horizon 6
- Get top X in races using random types, brands, classes of cars
- Get top X in races using random cars (optional)
- Earn stars in PR Stunts and Horizon Story missions
- Pull off specific skills
- Set clean lap times on Rivals leaderboards or Monthly Rival leaderboard
- Beat closest rival in Monthly Rival leaderboard
- Playing online gamemodes and Eventlab tracks
- Complete time attack laps
- Complete job shifts (optional)
- Cruise between 2 locations usign random types, brands, classes of cars (optional)
- Cruise between 2 locations usign random cars (optional)
- Complete Mastery Tree of random types, brands, classes of cars (optional)
- Complete Mastery Tree of random cars (optional)
- Gift car (optional)
